Bastet Hieroglyphs is an open-source font for Egyptian hieroglyphs, made by the Bastet project.

It aims to arrange signs into quadrats (stacked and grouped signs) using the Unicode Egyptian Hieroglyph Format Controls (U+13430 to U+1343F), so text written in Unicode looks the way it does on monuments and in grammar books.

To contribute or report an issue, please visit github.com/bastet00/bastet-fonts.
